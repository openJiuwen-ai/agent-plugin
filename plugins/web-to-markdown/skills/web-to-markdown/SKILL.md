# 网页转 Markdown 笔记

## 目标

把用户指定的网页正文转换为结构化的 Markdown 笔记，并可按需保存为 `.md` 文件。

- 核心目标：Markdown 正文必须来自 `web_to_markdown` 工具的真实返回值，禁止自行编造网页内容。
- 关键成功条件：笔记包含标题与正文；正文与工具返回的 `markdown` 字段一致；来源 URL 被如实保留。

## 工作流

1. 确认目标 URL：若用户消息中已给出链接则直接使用；否则先询问用户要转换的网页地址。
2. 调用 `web_to_markdown` 工具，入参 `url` 为完整网页地址（含 `http://` 或 `https://`）。
3. 检查返回值：`success=false` 时向用户说明错误原因（如网络失败、网页无正文）并停止；`success=true` 时进入第 4 步。
4. 按以下模板输出笔记：

```
# {title}

> 来源：{url}

{markdown}
```

5. 若用户要求保存为文件：把上述笔记内容写入 `<标题或域名>.md`（文件名去除非法字符，避免覆盖既有文件）；若用户未要求保存，则直接在对话中展示笔记。

## 验收标准

- 正文内容与工具返回的 `markdown` 逐字一致，不擅自增删或改写。
- 标题与来源 URL 如实呈现；抓取失败时明确告知原因，不生成空笔记。
- 保存文件时文件名合法，且内容与对话中展示的笔记一致。
