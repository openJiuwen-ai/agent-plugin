# PROVENANCE / 来源说明

- **本插件**：`http-api-probe`，Apache-2.0 许可（见本目录 [LICENSE](./LICENSE)），代码与文档均为本仓独立编写。
- **功能参考**：postmanlabs/postman-mcp-server（厂商 MCP 项目）。本插件仅将其作为「API 测试类工具的工作流形态」（先观测、再断言、结果可复核）的**灵感参考**；**未复制、移植或改写其任何源码、提示词、测试或配置**，也不宣称与其能力覆盖等同。
- 本插件的 localhost 限制、无凭据 / 无 cookie 策略、不跟随重定向、忽略环境代理、有界读取与断言机制，均为基于 Python 标准库 `urllib` 公开文档的独立实现，与参考项目不存在代码层面的派生关系。
- 参考项目的许可不适用于本包；引用其能力时请遵循其自身许可。
